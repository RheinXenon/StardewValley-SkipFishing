# Skip Fishing Minigame - 跳过钓鱼小游戏

自用试写的星露谷物语钓鱼辅助mod，可以跳过钓鱼小游戏、自动钓鱼，并根据钓鱼等级自定义鱼的品质。

## 功能特性

### 核心功能

1. **跳过钓鱼小游戏** - 自动完成钓鱼小游戏，直接获得鱼
2. **自动抛竿和收杆** - 自动抛出鱼竿，当鱼咬钩时自动收杆
3. **自动取出宝箱物品** - 自动拾取钓鱼宝箱中的所有物品

### 品质系统

- 根据钓鱼等级自动调整鱼的品质
- 等级1-3：普通品质
- 等级4-6：银星品质
- 等级7-9：金星品质（有概率升级到铱星）
- 等级10：80%概率铱星品质，20%概率金星品质（概率可自定义）

### 按键控制

- **F5** - 切换Mod总开关（开启/关闭所有功能）
- 按键可以在配置菜单中自定义
- 具体启用哪些功能可在配置菜单中勾选

## 安装方法

1. 确保已安装 [SMAPI](https://smapi.io/)
2. 下载本mod
3. 解压到 `Stardew Valley/Mods` 文件夹
4. 需安装 [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098) 以获得图形化配置界面

## 配置说明

### 通过Generic Mod Config Menu配置（推荐）

1. 在游戏主菜单或游戏内按 ESC
2. 点击"Mod Options"
3. 找到"Skip Fishing Minigame"
4. 调整各项设置

### 按键配置

- **切换Mod总开关** - 设置切换整个Mod开关的按键（默认F5）

### 功能选择

在Mod启用状态下，可以通过勾选来选择使用以下功能：

- **跳过钓鱼小游戏** - 勾选后自动完成钓鱼小游戏
- **自动抛竿和收杆** - 勾选后自动钓鱼（抛竿+收杆）
- **自动取出宝箱物品** - 勾选后自动拾取钓鱼宝箱内的物品

### 品质配置

- **启用等级品质提升** - 是否根据钓鱼等级提升鱼的品质
- **满级铱星概率** - 钓鱼等级10级时获得铱星品质的概率（0-100%）

### 其他设置

- **显示状态消息** - 切换功能时是否显示HUD消息
- **自动抛竿延迟** - 自动抛竿前的延迟时间（毫秒）
- **收杆检测间隔** - 检测鱼咬钩的间隔时间（毫秒）

## 技术信息

- 兼容 SMAPI 4.0.0+
- 兼容 Stardew Valley 1.6+
- 目标框架: .NET 6.0
- 支持多人游戏（每个玩家独立配置）
